Esse código tem o objetivo de prover uma máquina virtual Debian13 com apache instalado
Como subir a VM:
 1 - Instale o Vagrant
 2 - Instale o Virtualbox
 3 - Instale o Vagrantfile e a pasta meu-site para o seu diretório de preferência
 4 - Nesse diretório abra o terminal
 5 - Execute vagrant init
 6 - Execute vagrant up
 7 - Execute vagrant ssh

Para acessar o site escreva localhost:8080 no seu navegador.

Nota: Na linha 47, altere o caminho da pasta compartilhada para a sua pasta escolhida.
